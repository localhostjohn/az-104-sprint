# AZ-104 Sprint

A focused study game for the Microsoft Azure Administrator exam.

- 80 original questions spanning every objective in the April 2026 AZ-104 skills outline
- 10-question teaching sprints with instant explanations
- Weighted 50-question mock exams with a 100-minute target
- Score history, average, personal best, and 800+ readiness tracking

## Run locally

```bash
npm install
npm run dev
```

## GitHub Pages

The included GitHub Actions workflow builds and deploys the static Pages edition after a push to `main`. Because GitHub Pages is static hosting, that edition stores score history in the current browser. The private OpenAI Sites deployment uses its database for durable history.

This is an independent study aid. Questions are original and aligned to the [official Microsoft AZ-104 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-104).
